Backbone RMSE (ppm) on UCBShift's 200-protein crystal test set against UCBShift's deposited labels, on the 69,595 cells common to all four methods (184 chains; per-method preprocessing failures shrink the intersection). Some cells, as well as the C$'$ entries of 3 anticorrelated proteins, are excluded from the test set as in the UCBShift paper\cite{UCBShift}. Homology modules are patched so that no predictor can retrieve the target protein's own BMRB entry, any entry sharing its UniProt accession, any reference keyed to its own PDB entry, or any reference at $\geq$95\% sequence identity over $\geq$90\% of the shorter sequence, and any reference in its UniRef100 cluster. Bold marks the lowest RMSE for each nucleus; an asterisk marks a lead over the runner-up whose 95\,\% paired interval excludes zero, and a dagger such a lead of DeepShift over UCBShift-X, from 2,000 bootstrap resamples of chains, seed 20260806.
