Backbone MAE (ppm), all predictors. Provided separately for AlphaFold, X-ray, and NMR structures. Every predictor is scored on one frozen master cell set per nucleus (1,567 structure instances, 667,465 backbone cells). CAMSHIFT on C$\beta$ and PLM-CS on every nucleus are outside the master set and are scored on the master cells they return, marked $^{\ast}$ with the cell count printed beneath the row. PLM-CS had 334 depositions in the benchmark in its training set which are not reported.
