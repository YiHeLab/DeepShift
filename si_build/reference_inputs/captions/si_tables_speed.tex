Wall-clock time to predict one protein. RTX 5090, Intel Core Ultra 7 265K. Clock starts when method is handed the first single-chain PDB and ends when predictions exist, including process start, model load, hydrogenation, feature building and output parsing, etc (one protein per invocation also shown). Seconds per protein is mean over 203 crystal structures with 95\% confidence interval. Milliseconds per residue is cohort total divided by total residue count. In the per-invocation block, milliseconds per residue is the time per residue after startup (startup fitted as non-negative). Chains it finishes is the percentage of 240 crystal chains, a wider set than the 203 timed, for which the method returns predictions.
